## PropertyHandoverManagement
# The problem

During construction inspections and residential handovers, defect details, photos, assigned contractors and repair updates can become scattered across spreadsheets, email and messaging apps. This makes it harder to track outstanding issues and verify that repairs are complete.

# The solution

A centralised web app where a small construction team can register properties, record defects, assign responsibility, track repairs and review what remains outstanding before handover.

# Target user

A site supervisor, defects coordinator or small property handover team managing one or more residential projects.
